Let's see why.

```rust
let s1 = String::from("hello");

let len = calculate_length(&s1);
```

Here:

```rust
&s1
```

means:

> "Borrow `s1`, don't take ownership."

So ownership never leaves `s1`.

Visual:

```text
s1 ------> "hello"

calculate_length()
      ^
      |
   borrowed reference
```

The function receives:

```rust
fn calculate_length(s: &String) -> usize
```

which means:

> "I only want to read the String. I don't want to own it."

After the function returns:

```rust
println!("{} {}", s1, len);
```

`s1` is still valid because it was only borrowed.

---

If the function was:

```rust
fn calculate_length(s: String) -> usize {
    s.len()
}
```

and called like:

```rust
let len = calculate_length(s1);
```

then ownership would move into the function and this would fail:

```rust
println!("{}", s1); // ❌
```

because `s1` would no longer own the String.

---

### Key Idea

* `s1` → ownership moves
* `&s1` → immutable borrow (read-only)
* `&mut s1` → mutable borrow (can modify)
